# src/

Implementation code for FashionOS lives here.

No application code has been written yet. Development follows the phased roadmap in [`../docs/DEVELOPMENT_ROADMAP.md`](../docs/DEVELOPMENT_ROADMAP.md), beginning with **Phase 0: Environment and Repository Setup**.

The main application is built as a single modular WordPress plugin named `fashionos`, with an independently designed React + TypeScript frontend compiled by Vite. See Section 5 of the [Master Technical Specification](../FashionOS_Master_Technical_Specification.md) for the intended plugin and React application structure.
